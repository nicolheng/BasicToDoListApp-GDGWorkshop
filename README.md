# M6 – LocalStorage

This branch adds persistence so that tasks remain saved even after refreshing the page.

Participants learn how to, load initial tasks from `localStorage`, handle empty or missing data safely, save tasks automatically using `useEffect`, keep the UI in sync with local storage updates
